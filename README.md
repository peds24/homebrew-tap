# peds24/homebrew-tap

Personal Homebrew tap for [Pedro Serdio Hank](https://github.com/peds24)'s macOS apps.

## Install

```bash
brew tap peds24/tap
brew install --cask da-miniplayer
```

## Casks

- **da-miniplayer** — [DA Mini Player](https://github.com/peds24/dA-spotify-miniplayer), a floating Spotify mini player. Currently in alpha; see that repo's README for details.
